# 🏡 HBnB

A simple and friendly web application for discovering places, viewing details, and sharing reviews.

## 🎨 Design

The website uses a calm blue color palette:

- 🌊 Soft Blue: `#D9EBF2`
- 🩵 Light Blue: `#EEF6FA`
- 🔵 Button Blue: `#6B9EB5`
- 🤍 White: `#FFFFFF`

## ✨ Features

- 🏠 Browse places
- 🌍 Filter places by country
- 🔐 User login with JWT authentication
- 🏡 View place details and amenities
- ⭐ View and add reviews
- 👑 Admin support
